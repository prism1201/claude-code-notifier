# Claude Code Notifier

Windows desktop toast notifications for [Claude Code](https://code.claude.com) — with **click-to-focus**.

When Claude finishes a task or needs your confirmation, a native Windows toast notification pops up. **Click the notification** and it instantly brings the Claude Code terminal window to the foreground — no flashing cmd windows.

## Features

- **Zero dependencies** — pure PowerShell, no npm, no Python, no modules
- **Click-to-focus** — click the toast to jump straight to Claude Code terminal (never a browser)
- **No flash** — VBS bridge eliminates the console flash on activation
- **Three hook events** — `Stop` (task complete), `PermissionRequest` (needs confirm), `Notification` (system messages)
- **Smart skip** — won't notify if Claude terminal is already in foreground
- **Deduplication** — won't spam multiple notifications for the same event within 5s
- **Toggle on/off** — `toggle.ps1` to disable/enable notifications anytime
- **One-command setup** — just run `setup.ps1`

## Quick Start

```powershell
# 1. Clone or download this repo
git clone https://github.com/YOUR_USERNAME/claude-code-notifier.git
cd claude-code-notifier

# 2. Run setup (registers protocol + configures hooks)
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

That's it. The next time Claude Code finishes a task or asks for permission, you'll get a toast. Click it to jump back.

## How It Works

```
Claude Code hook fires
  → notify.ps1 shows Windows Toast (with claude-focus:// protocol)
    → You click the toast
      → wscript.exe silently runs focus-claude.vbs
        → focus-claude.ps1 finds & activates the Claude terminal window
```

## Files

| File | Purpose |
|------|---------|
| `setup.ps1` | One-click installer: registers protocol + configures hooks |
| `notify.ps1` | Sends Windows toast notification |
| `focus-claude.ps1` | Finds and focuses the Claude Code terminal window |
| `focus-claude.vbs` | Silent launcher (generated by setup, avoids console flash) |
| `toggle.ps1` | Toggle notifications on/off |

## Toggle On/Off

**Double-click the desktop shortcut** `Claude通知开关` — a toast confirms the new state, no terminal window flashes.

Or from command line:

```powershell
# Turn off
powershell -File .\toggle.ps1

# Turn back on
powershell -File .\toggle.ps1
```

## Uninstall

```powershell
# Remove protocol registration
Remove-Item -Path "HKCU:\SOFTWARE\Classes\claude-focus" -Recurse -Force

# Remove hooks from settings.json (or delete them manually)
```

## Requirements

- Windows 10 or 11
- PowerShell 5.1+
- [Claude Code](https://code.claude.com) installed
